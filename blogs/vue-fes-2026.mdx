# 目次

# はじめに
10月24日に開催された [Vue Fes 2026](https://vuefes.jp/2026/) に参加してきました。

僕は普段は Next.js を使ってフロントエンドを組むことが多く、 Vue.js はあまり触ったことがありません。
ですがサークルのサービスではほとんどが Vue.js を使っていて何かと縁があり、学生支援制度もあって、折角ならと参加してきました。

# セッションなど

僕が聴講・参加したセッションの感想を書いていきます。

## キーノート
Vue.js 作者の Evan You によるキーノート。 Vue.js の近況やらその周辺のツールチェーン、 TypeScript 7.1 への Vue.js の対応等を話してくれました。
フロントエンドは作れたらいいやの精神でこれまでやってきたので、最近の TypeScript がどうとかいう情報はそこまで追っていなかったのですが、TS 7.1はかなり興味深い機能があるらしい。
それが Content Mapper というもので、Vueもこれを取り入れていくとのこと。
キーノートに限らず色々なセッションで Content Mapper の話は上がっていて、かなり革新的な機能なんだろうなぁと思いました。

Vue Fes の開幕が Vue.js 作者なのは楽しいですね。本物が目の前にいる感覚は気分を高揚させるものです。
一点、パネルディスカッションでもそうでしたが、僕の英語能力の1.5倍くらいの流量で英語が流れてくるので内容理解がかなり辛かった...

https://vuefes.jp/2026/event?section=student-support-contents#student-support-contents

背景も様々で、中には航空宇宙分野という超低レイヤーのものを持つ人までいました。それでも今回の Vue Fes に参加したきっかけを聞くと、学生支援制度が使えるから、という答えが返ってきました。
巷のカンファレンスの参加費が学生にとって安いとは言えないほどの額であるところに、参加費負担なしでカンファレンスに参加できるのは非常に助かりました。
特に今まで Vue.js を触ったことがないような人でも、金銭的負担の軽さから興味本位で参加しやすくなっている程に、今回の支援制度には頭が上がりません。
学生支援制度を今年も行ってくださった運営の方々、及びスポンサーの企業様、ありがとうございました。

## ハンズオン

https://vuefes.jp/2026/event?section=hands-on#hands-on

[chibivue](https://book.chibivue.land/) をほんの一部だけ作ってみることを目標としたハンズオンです。
[Web上にbook公開されていて](https://book.chibivue.land/ja/10-minimum-example/010-create-app-api/index.html)、大まかにそれを進める形で進んでいきました。
コードをコピペしながら2時間程進めていっていたので、分量としてはなかなか多いと思います。

まずは JS/TS を使った動的なDOM操作から始まり、それを抽象化した仮想DOMを作り、それをもとに簡易的なリアクティブなアプリケーションの構築までを行いました。
スクリプトを使ったDOM操作は色々なところでやりますが、リアクティビティシステムの構築はやったことがなく、それをさせてくれるのは非常に面白かったです。
その中で、リアクティビティの実現に対して chibivue は Proxy を用いるらしく、原理としてはなかなか単純なものなのは驚きました。
もっとも、これにv-ifやv-forといった機能を追加する場合にはもっと複雑な制御が必要になるのだと思います。

僕が聴講した範囲では Vue.js そのものにフォーカスを当てたセッションが少ない中、このような経験ができたのは良かったです。

## The Vue Toolchain, Reimagined

https://vuefes.jp/2026/speaker/ubugeeei

Vue.js 周辺のツールチェーンに関して、スピーカーの ubugeei さんの開発している [Vize](https://vizejs.dev/) (読み方: ビーズ) の紹介です。
AI時代では開発のループにツールを用い、その品質の担保が必要不可欠です。
最近では React Compiler や celld のように、そういったツールが Rust で整備されることも少なくありません。
(TypeScript 7 が Go で実装されているのは少し意外でした。そこで出しゃばらなくていいのに)

こうしたものを TypeScript のフロントエンドで考えると、コードを変更した後にはビルドやリンターチェック、型チェックが待っています。
もしこれらを高速に、一括で行えるとすれば非常に便利になります。
そういったものを実現するものとして Vize が紹介されました。

僕の感じた Vize の特徴的な点をいくつか挙げると、まず linter のルールが豊富であること。それもよく使われるようなものから非常にニッチなものまで揃っているようです。
次にテストが非常に多いこと。セッションでは、全てのバグ報告がテストとして組み込まれているそうです。バグを一度修正したら、同じバグは二度と起こさせない。
当然といえばそこまでですが、簡単なことではないと思います。
こうしたテストはおよそ3万件あるとのことです。
僕の感覚だとテストは数百あれば多い方だと思っていたのですが、桁違いなテスト件数に驚きました。

linter やテストの豊富さは、全て Vize に寄せられる issue 等を通した事例報告が起点になっているらしい。
諸々の規模が大きいだけに面食らうところもありますが、やはりこの部分は OSS の強さを感じるとともに、ubugeei さんの Vize を仕上げることの意気込みを思い知りました。

# セッション外・全体を通して

Vue Fes、Vue.js と聞いてのこのこやってきたら、 Vite や VoidZero 、或いはそのさらに周辺の抽象度を少し上げた話題の多いカンファレンスだなぁと感じました。
その多くのテーマに Evan You の息がかかっていたり、 Evan You 自身も cloudflare に就職してなかなか無敵になっていたりという背景からも、このイベントは Vue.js を入り口としてツールチェーンやOSSまで関心が広がるコミュニティなのだと感じました。
パネルディスカッションでは Vue.js の話題に限らず (というよりその話題を触れずに超えて) 昨今の JavaScript のエコシステムについて議論をしていたり、一瞬 OSS そのものの将来に触れていたりしていたのには、その関心の広さが現れているのでしょう。
特にそこで話していた方々の肩書は Vue.js の範疇におさまらず、 Vue.js を触っていなくとも知っているようなコミュニティに所属する方ばかりでした。幅広い関心を持つコミュニティの中で、上を見た時にいつも良く知る人間がいるのは Vue.js の持つ特徴だと思います。
